# Dynamic_cab_price_estimator_model-
Dynamic Cab Pricing Predictor — an end-to-end ML project estimating Ola/Uber-style fares from rider demand, driver supply, ride history, duration, and booking time. Uses a scikit-learn preprocessing pipeline with a Linear Regression model (R²=0.87, MAE≈52), served via FastAPI with a live HTML/JS frontend.
